What MPAE Does

Five services, one pipeline

MPAE is split into five microservices, each owned end-to-end by one person on the team.

01

Auth & Gateway

A NestJS API Gateway handles JWT authentication and role-based access control, then routes every request to the right service.

02

Data Service

Ingests raw machine and sensor data, cleans it with Pandas, and publishes a canonical stream the rest of MPAE can trust.

03

KPI Service

Calculates OEE, throughput, downtime, and scrap rate from clean production data, continuously and in real time.

04

AI/ML Service

Runs Isolation Forest anomaly detection, then hands flagged events to an LLM that writes a plain-language explanation.

05

Dashboard

The Next.js frontend renders live KPIs, anomaly alerts, and AI insights in a dashboard operators check every shift.
